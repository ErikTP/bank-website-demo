Frågor och svar

Vanliga frågor

Fråga 1: Hur blir jag kund?


Svar: Du kan ansöka om att bli kund genom att klicka här för att komma till första sida.


Fråga 2: Vilka tjänster erbjuder ni?


Svar: Vi erbjuder ett bredd utbud av finansiella tjänster, inklusiv rådgivning, investeringar och med mera.

Fler vanliga frågor


  • Hur spärrar jag mitt bankkort?
    • För att spärra ditt bankkort, kontakta din kundtjänst omedelbart via telefon eller använd mobilappen.

  • Hur kommer jag snabbast i kontakt med er?
    • För att snabbt komma i kontakt med oss kan du ringa vår kundtjänst på vårt telefonnummer eller använda livechattfunktionen på vår hemsida

  • Finns det någon uppsägningstid hos er när man vill avsluta som kund?
    • Nej, hos oss finns ingen uppsägningstid. Du kan avsluta ditt konto när som helst utan några extra avgifter.
